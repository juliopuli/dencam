# ExcelAtenciones V2.1

Aplicación web local para la gestión de atenciones con integración de Excel.

## Requisitos
- Windows
- PowerShell
- Microsoft Excel instalado localmente

## Inicio rápido
1. Ejecuta `Inicia_Servidor.bat`.
2. Abre `index.html` en tu navegador.
3. Configura las rutas de tus archivos Excel en la interfaz.

## Estructura del Proyecto
- `index.html`: Interfaz de usuario con sistema de pestañas.
- `styles.css`: Estilos corporativos (Rojo y Blanco).
- `app.js`: Lógica de búsqueda global y gestión de datos.
- `bridge.ps1`: Servidor intermedio (PowerShell) para lectura/escritura en Excel.
- `Inicia_Servidor.bat`: Lanzador del servidor local.
